# m5-paper-nano-lora-transceiver-jp

M5Paper Mono (C153) と SX1262 LoRa 無線を使った、日本向け設定の送受信デモです。
画面表示、タッチ送信、受信メッセージ表示、フロントライト操作を1台のPaperで確認できます。

> このリポジトリは無線機器の技術基準適合を保証するものではありません。
> 日本国内で送信する前に、末尾の「日本の電波法に関する注意」を必ず確認してください。

## ハードウェア

- M5Paper Mono C153（LoRa搭載モデル。C153-LITEはLoRa非搭載）
- ESP32-S3R8、16MB Flash、8MB Octal PSRAM
- 内蔵LoRa: SX1262
- 外部送信側の例: M5Stack Cardputer ADV + Cap LoRa-1262

PaperMono側のLoRa配線は次のとおりです。

| 信号 | PaperMono |
| --- | ---: |
| SCK | GPIO39 |
| MISO | GPIO40 |
| MOSI | GPIO38 |
| NSS | GPIO41 |
| DIO1 / IRQ | GPIO5 |
| BUSY | GPIO21 |
| 電源有効化 | M5PM1 GPIO2 |
| RST | M5IOE1 pin10 |
| アンテナ切替 | M5IOE1 pin2 |

## 通信設定

送信側とPaper側の値を完全に一致させてください。

| 項目 | 設定値 |
| --- | --- |
| 周波数 | 920.6 MHz |
| 帯域幅 | 125 kHz |
| Spreading Factor | SF7 |
| Coding Rate | 4/5 |
| Sync word | 0x34 |
| 送信出力設定 | 13 dBm |
| TCXO | 3.0 V |
| Preamble | 10 |

## ビルドと書き込み

PlatformIOとArduinoフレームワークを使用します。依存ライブラリは`platformio.ini`を参照してください。

```bash
pio run -e papermono
pio run -e papermono -t upload --upload-port /dev/cu.usbmodemXXXX
```

macOSでポートがbusyになる場合は、別のシリアルモニターを終了してから再実行します。
書き込み後はPaperが自動リセットされます。

## 操作方法

| 操作 | 動作 |
| --- | --- |
| 起動 | LoRaを初期化し、受信待ちになります |
| 受信 | メッセージ窓を更新し、効果音とLED点滅を行います |
| タッチ | 現在表示中の文字列を送信します |
| BtnA | フロントライトを暗くします |
| BtnB | フロントライトを明るくします |
| USBシリアル入力 | 1行入力してEnterで、その文字列を送信します |

シリアルモニターは115200 baudです。起動後、次のようなログで状態を確認できます。

```text
[LoRa] ready: 920.6MHz BW125 SF7 CR5 sync 0x34
```

2秒ごとの診断ログでは、IRQ受信回数、正常読み出し回数、CRCなどの読み出しエラー、
受信待ち開始エラーを確認できます。送信側と設定が違う場合はIRQが増えません。

## 日本の電波法に関する注意

このコードの`920.6 MHz`は、日本の920 MHz帯を想定したソフトウェア設定です。
868 MHzはEU向けの設定であり、日本向け設定ではありません。

ただし、周波数を920 MHz帯へ変更し、出力を13 dBmに設定しただけで合法になるわけではありません。
日本国内で電波を送信するには、少なくとも次を確認してください。

1. 使用する無線モジュールに、日本向けの技術基準適合証明・工事設計認証と技適マークがあること。
2. 認証時のアンテナ、アンテナ利得、給電条件、筐体条件から変更していないこと。
3. 認証された無線設備の周波数、占有帯域幅、空中線電力、送信時間制限、キャリアセンス等の条件を守ること。
4. ファームウェアで出力や変調条件を変更する場合、その変更後の構成が認証範囲内であること。
5. 技適のないSX1262モジュールを組み込んだ自作機を、免許不要機器として送信しないこと。

M5Stack Cap LoRa-1262の製品仕様には868〜923 MHz、最大+22 dBmと記載されていますが、
対応周波数・最大出力の記載だけでは日本の技適取得済みであることを意味しません。
モジュール本体と販売元の認証情報を個別に確認してください。

日本の920 MHz帯の制度・技術条件は、総務省の現行法令・告示およびARIB STD-T108を確認してください。
本リポジトリの設定値は学習・検証用の例であり、法的適合性の判断や免許申請の代わりにはなりません。

- [ARIB STD-T108: 920MHz帯テレメータ用、テレコントロール用及びデータ伝送用無線設備](https://www.arib.or.jp/kikaku/kikaku_tushin/desc/std-t108.html)
- [総務省 電波利用ホームページ](https://www.tele.soumu.go.jp/)
- [M5Stack Cap LoRa-1262仕様](https://docs.m5stack.com/ja/cap/Cap_LoRa-1262)

## 制限事項

- 実機での表示・LoRa初期化・Paperへの書き込みは確認済みですが、通信相手との日本向け実電波試験は別途必要です。
- `startReceiveDutyCycleAuto()`は実機でウォッチドッグリセットが発生したため無効化しています。
- E-Inkの部分更新にはゴーストが発生する場合があります。
- C153-LITEにはLoRaハードウェアがありません。
